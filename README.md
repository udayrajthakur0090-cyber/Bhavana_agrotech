# Bhawana Biotech website

A responsive one-page website made with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open the `bhawana_biotech_website` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — mobile menu, active navigation, and enquiry email draft

## Before publishing
- Confirm the official company name, phone numbers, email addresses, address, domain and team details.
- Replace the demo/remote Unsplash images with company-owned photos where possible.
- The contact form uses `mailto:` and does not store or submit data to a server. Connect a backend or a form service if you need live form submissions.
- Add a privacy policy and verify all SEO information before launch.

This website uses external Google Fonts and Unsplash image URLs, so those assets require an internet connection.
